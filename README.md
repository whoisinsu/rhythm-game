# RHYTHM

브라우저에서 바로 실행되는 4키 리듬게임입니다. 로그인 없이 정적 HTML/CSS/JS 한 파일로 동작합니다.

## 실행 방법

`index.html`을 정적 호스팅(GitHub Pages)으로 열면 바로 플레이할 수 있습니다. 별도 빌드/설치 과정이 없습니다.

## 규칙

- `H` `J` `K` `L` 키로 각 레인에 내려오는 노트를 판정선에서 맞춥니다.
- 판정선 근처에서 정확히 맞추면 PERFECT/GOOD, 놓치면 MISS로 체력이 깎입니다.
- 체력이 0이 되면 Fail, 30초 곡을 끝까지 버티면 Clear입니다.
- 조작: `H`/`J`/`K`/`L` (레인 히트), `Esc` (일시정지/재개), `Space`/`Enter` (시작·다시 시작)

## 짧은 확인 방법 (4줄)

1. **위치**: 배포된 index.html 주소를 새 시크릿 창에서 연다.
2. **3단계 이내 행동**: (1) "시작" 버튼 클릭 → (2) `H`/`J`/`K`/`L` 키를 판정선에 맞춰 입력 → (3) 30초간 노트를 처리한다.
4. **통과 모습**: 30초 경과 시 상태가 "Clear"로 바뀌고 결과 화면에 점수·최대 콤보·생존 시간이 표시되며, "다시 시작"으로 즉시 새 판이 시작된다.
5. **안 될 때 모습**: 체력이 0이 되면 즉시 "Fail" 결과 화면이 뜨고, 놓친 노트마다 판정선 위에 MISS 표시가 남는다.

## 난이도 테스트 방법

노트 배치(채보)는 고정된 시드로 생성되어 항상 동일합니다. 화면의 "난이도(속도)" 값만 유일한 조정 변수이며, 이 값 하나만 바꿔가며 같은 조건으로 10판씩 플레이하면 라운드 종료마다 결과(Clear/Fail, 점수, 최대 콤보)가 자동으로 기록표에 저장되고 "기록표 CSV 내보내기"로 내려받을 수 있습니다.

1. 현재 난이도 값으로 10회 플레이 (기록 자동 저장)
2. 난이도 값 하나만 변경 후 10회 플레이
3. CSV로 내보내 두 묶음의 점수/생존 결과 범위·중앙값을 비교해 최종 값을 결정

## 저장 데이터

- `localStorage`에 최고 점수·최고 콤보·플레이 로그만 저장됩니다 (현재 판 진행 상태는 저장하지 않고 매번 초기화됩니다).
- 저장값이 비어 있거나 손상되어도 게임은 중단되지 않고 기본값(최고 점수 0, 빈 로그)으로 시작합니다.
- "저장 기록 초기화" 버튼으로 언제든 리셋할 수 있습니다.

## 개인정보/비밀값

- 외부 API 호출이나 서버 통신이 없으며, 개인정보나 비밀값을 수집·저장·표시하지 않습니다.
- 효과음은 브라우저 내장 WebAudio로 즉석 생성하며, 배경 음악 파일 등 외부 리소스를 불러오지 않습니다(제목 글꼴만 Google Fonts에서 불러옵니다).

## AI와 나의 판단

1. **AI에게 맡긴 일**: 게임 로직/렌더링/저장·복구 코드 전체 구현, 해상도·연타 입력·포커스 이탈·일시정지·저장 손상 복구 등 자동화 가능한 항목의 브라우저 테스트.
2. **직접 판단한 일**: 게임 장르(리듬게임)와 조작키(H J K L) 결정, 타이틀 글꼴(Bungee) 선택, 결과 화면 문구(Fail/Clear) 결정, 소스 공개 방식(GitHub 공개 저장소 + Pages) 결정, 난이도 테스트에 쓸 실제 10+10회 플레이와 최종 난이도 값 선택.
3. **AI 제안을 따르지 않은 일**: (실제로 다르게 판단한 부분이 있다면 이 줄에 구체적으로 적을 것. 없다면 "제안대로 진행함 — 요구사항과 충돌하는 지점이 없었기 때문" 등 이유를 남길 것.)
